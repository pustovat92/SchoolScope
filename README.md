# SchoolScope 0.4

Portable-приложение для Windows 10/11 x64: характеристики ПК, список установленного ПО, сетевые подключения, диагностика HTTPS и небольшая комната для общения.

## Запуск

Скачайте `SchoolScope.exe` из GitHub Releases и запустите обычным пользователем. Установщик, Python и отдельная установка .NET не нужны: среда включена в EXE. При первом запуске нативные библиотеки .NET распаковываются во временный каталог пользователя. Исполняемый файл пока не подписан; Windows или политика школы может запретить его запуск. Попросите администратора согласовать программу.

В каждой рабочей вкладке есть кнопка **Как пользоваться**, общая инструкция находится в отдельной вкладке.

## Диагностика

1. **Компьютер → Проверить**: ОС, CPU, RAM, GPU, диски, программы из реестра, профили брандмауэра, автозагрузка, последние установленные исправления. Вывод обновлений не доказывает, что система полностью обновлена.
2. **Подключение → Проверить**: интерфейсы, IP, DNS, шлюзы, маршруты по умолчанию, доступные сведения Wi-Fi/VPN, системные прокси и активные записи hosts. Это помогает выяснить, как подключён ПК, без изменения сети. Часть сведений может быть недоступна по политике Windows.
3. **Проверка сайта**: введите HTTPS-адрес. Последовательно проверяются DNS, прямое TCP-соединение и HTTPS с системным прокси. Перенаправления показываются, но не выполняются. Сертификаты проверяются штатно. Программа не называет продукт фильтрации без достаточных данных.
4. Сохраните HTML/JSON по желанию. Проверьте содержимое перед публикацией: отчёт может включать адреса, SSID, пути и сведения о ПО. Автоматического удаления личных сведений пока нет.

Portable-программы и некоторые Store-приложения могут отсутствовать в списке ПО. Сторонние VPN и DNS браузера не всегда видны в настройках Windows. Команды PowerShell используют фиксированные скрипты, пользовательский адрес не вставляется в команды оболочки. Пароли не извлекаются; настройки системы и сети не изменяются.

## Комната: два компьютера

1. На первом ПК задайте имя и нажмите **Создать комнату**. IPv4 подставляется автоматически: адаптеры со шлюзом получают приоритет. При нескольких сетях выберите нужный адаптер в списке.
2. На втором ПК нажмите **Найти комнаты**, выберите комнату и введите код, показанный на первом ПК, например `XXXX-XXXX-XXXX`. Нажмите **Войти**. Дефисы и регистр не важны.
3. Автопоиск работает в доступной локальной сети (UDP 45832). Он не ищет комнаты во всём интернете и не обходит изоляцию устройств.
4. Если автопоиск запрещён, на первом ПК выберите **Сохранить приглашение…**, перенесите файл `.schoolscope` на флешке и на втором выберите **Открыть приглашение…**. Переписывать JSON не нужно. Доступ к TCP-порту комнаты всё равно необходим.
5. Старый JSON можно вставить кнопкой **Вставить старый код**. Старое приглашение действует только пока работает создавшая его комната.
6. Сообщения и файлы получают все участники. Файлы сохраняются после подтверждения.

Во вкладке **Программы** список представлен таблицей: название, версия, издатель. Поиск работает по всем трём колонкам; нажатие на заголовок меняет сортировку. Экспорт сохраняет отфильтрованный список. Во вкладке «Компьютер» отображается число программ, без длинного списка.
Первый компьютер должен оставаться включённым. Если Windows запрашивает разрешение входящих соединений, согласуйте его с владельцем сети. Программа не изменяет брандмауэр. Устройства одного Wi-Fi могут быть изолированы. Провод и Wi-Fi могут, наоборот, входить в одну сеть. При тайм-ауте проверьте IP, запущенную комнату, порт и сетевые ограничения с администратором.

**Разные сети:** клиент может подключаться по DNS-имени или публичному IP узла комнаты. Но доступный сервер и его входящий порт должен предоставить администратор. Размещённого сервера, NAT traversal и автоматического резервного маршрута здесь нет. GitHub хранит исходники и релизы, не работающий сервер. Не открывайте школьный роутер самостоятельно.

## Ограничения и защита

- До 16 соединений на комнату, имена до 40 символов, сообщения до 4000 символов.
- Автопоиск передаёт название комнаты, порт и сертификат, но не секрет входа. Ответ привязан к запросу и защищён HMAC, который проверяется введённым кодом до TLS-подключения. Код содержит 12 случайных символов (около 59 бит); сертификат затем проверяется по отпечатку. Код и файл приглашения не публикуйте. Это не проверенный внешним аудитом протокол; для публичного сервиса нужна отдельная оценка безопасности.
- TLS 1.2/1.3; сертификат узла проверяется по SHA-256 из приглашения. Сертификат создаётся заново для каждой комнаты, секрет — случайный. Приглашение нужно передавать доверенным способом.
- Это шифрование между клиентом и узлом комнаты, **не сквозное шифрование**. Узел видит содержимое. Имена не подтверждают личность.
- Общая комната, без личных сообщений и списка участников в этой версии. Каждый с приглашением получает весь поток.
- Файлы до 4 МиБ целиком передаются в память; подтверждение требуется для записи на диск, а не для получения байтов. Не отправляйте конфиденциальные файлы в общую комнату. Передача частями и предварительное согласие до загрузки запланированы.
- Нет дисковой истории, офлайн-доставки, подтверждения прочтения, возобновления передачи или автоматического переподключения.
- Это первая экспериментальная версия, не проверенная на устойчивость к DoS и не предназначенная для открытого публичного сервера с недоверенными участниками.
- Управление фильтрами, изменение DNS/прокси и извлечение Wi-Fi-паролей не реализованы.

## Сборка разработчиком

Нужны Windows и .NET SDK 8. На компьютерах пользователей SDK не нужен.

```powershell
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None -o dist/win-x64
```

Самопроверка (локальный TCP/TLS, реальные read-only сведения о текущем ПК):

```powershell
$p = Start-Process .\dist\win-x64\SchoolScope.exe -ArgumentList '--self-test' -Wait -PassThru
Get-Content .\self-test-result.txt
$p.ExitCode
```

Тест проверяет двух участников, Unicode, файл 4 МиБ, неверный секрет, подменённый сертификат, слишком большой сетевой кадр, фильтрацию URL и сбор системных сведений. Проверка на двух физических ПК и в школьной сети выполняется отдельно.

## Публикация на GitHub

Создайте репозиторий и загрузите исходники без bin/obj/dist и личных отчётов. Workflow собирает EXE вручную или после push. Скачайте артефакт сборки, создайте Release с тегом `v0.4.0` и приложите EXE и SHA256SUMS.txt. Публикация из текущей рабочей папки автоматически не выполнялась.


## Блокировки (версия 0.3)

Вкладка «Блокировки» содержит список сайтов с галочками, добавление своего HTTPS-адреса, последовательную проверку и экспорт отчёта. Выделение строки открывает детали DNS/TCP/TLS/HTTP. Остановка завершает текущую проверку и пропускает следующие. Сетевые запросы начинаются только по кнопке. По умолчанию отмечены YouTube и GitHub; есть также Discord, Яндекс Игры, ya.ru и Microsoft.

Краткий вывод — интерпретация наблюдений, не доказательство блокировки. HTTP 200 не гарантирует отсутствие страницы запрета, HTTP 403 может выдать сам сайт. Текст HTML читается в пределах 256 КиБ без исполнения JavaScript; видеопотоки не анализируются. Проверка одного URL не проверяет все домены сервиса.

В «Полезных ссылках» — запрошенные страницы https://github.com/Flowseal/zapret-discord-youtube и https://github.com/bol-van/zapret, GitHub Status. Ссылки проверены при подготовке 0.3; их доступность может измениться. Программа открывает браузер, но не скачивает, не устанавливает и не запускает сторонние инструменты.


## Источник ограничения (0.4)

«Блокировки → Источник ограничения → Собрать признаки на ПК» собирает DNS/маршруты/прокси/hosts, выбранные политики Chrome/Edge/Chromium/Yandex из HKLM/HKCU (32/64 бит), манифесты расширений текущего пользователя, работающие службы, до 100 активных блокирующих правил брандмауэра, доменное членство и отдельные признаки регистрации управления. Это не полный аудит UEM и не доказательство причинности. Установленное расширение не обязательно включено; применённые политики проверяются через chrome://policy или edge://policy. Firefox, WFP-драйверы и все возможные политики не охвачены.

Проверка сайта читает до 256 КиБ HTML/текста, сохраняет проверку сертификата, не выполняет JavaScript и не следует автоматически по редиректам. Отображает упоминания продуктов, фрагменты с причиной/категорией и текст без CSS. Скрытый цветом текст можно увидеть, но не текст, созданный скриптом или расширением. Упоминание производителя в HTML — только подсказка, оно может встречаться в обычной статье.

Если браузер показывает другую страницу: Ctrl+A → Ctrl+C на странице запрета → «Вставить текст страницы» либо «Открыть сохранённый HTML». Максимум файла 2 МБ, анализируются первые 262144 символа. Текст импорта и сбор признаков заменяют текущий результат; сохраните его при необходимости. Не импортируются cookies, история и пароли.

Справка о политиках: https://www.chromium.org/administrators/complex-policies-on-windows/ ; https://learn.microsoft.com/en-us/deployedge/microsoft-edge-policies/extensioninstallallowlist . Признаки управления сами по себе не доказывают активное MDM: https://learn.microsoft.com/en-us/entra/identity/devices/troubleshoot-device-dsregcmd .
